# Vídeo 3D Console

Cena 3D interativa (Three.js) com um console de videogame, controle e uma TV.

- **Modo Jogo**: a TV roda um mini-jogo de naves (demo automática; use ← → para jogar).
- **Modo Vídeo**: carregue qualquer arquivo de vídeo e ele passa na tela da TV em 3D.
- Clique no console (ou no botão ⏻) para ligar/desligar.
- Arraste para girar a câmera, role para aproximar.

## Como rodar

Abra `index.html` em um servidor local, por exemplo:

```bash
python3 -m http.server 8000
# acesse http://localhost:8000
```
